# MonoOto

[English](README.md)

MonoOtoは、片耳でステレオ音楽を聴く人が、左右チャンネル由来の情報を音色の手がかりによって区別できるかを調べる、実験段階のmacOS音声プロジェクトです。

両耳聴の回復、自然なステレオ定位の再現、聴力の改善、安全な音圧を保証するものではありません。左右チャンネルの識別実験に成功しても、それは人工的な手がかりを利用できたことを示すものであり、自然な空間聴覚の実証ではありません。

## プロジェクトの状態

MonoOtoは段階Aの初期工学試作です。完成した音楽プレーヤーではなく、公開済みリリースもありません。

現在の実装範囲:

- 決定的にオフライン検証できるステレオからモノラルへの音色符号化
- 共通ゲインと先読みピークリミッター
- WAV／AIFFの検証、デコード、サンプルレート変換
- 再生世代に基づく状態管理
- 明示的なCore Audio出力機器選択と無音の出力経路ホスト
- Swift PackageおよびXcodeの自動テスト

未完了の範囲:

- 有界リアルタイムキューとファイル再生コントローラー
- 通常の再生、一時停止、シーク、出力耳選択、聴取比較UI
- macOS 14.2での実機実行、検証機器の拡大、統合した再生経路の60分負荷試験
- 想定利用者による知覚評価

2026-09-10時点で、タスク1〜4は記録したmacOS／Apple Silicon／USB機器の範囲で実装・検証済みです。最新の確認ではSwift PackageとXcodeで各75テスト、Releaseビルドが成功しました。それ以前のタスク4検証では機器変更、スリープ、44.1／48 kHzのrenderと寿命を確認しています。最新のキャンセル・破棄修正後はUSB 48 kHzの寿命検証に再合格しましたが、44.1 kHzのプロファイルと物理的な切断・スリープ試験はその版で再実施していません。条件と制約は[検証記録](docs/verification/stage-a.md)を参照してください。次はタスク5の有界キューで、未着手です。

現在のアプリホストが出力するのは無音だけです。機器を選択しただけでは音声グラフを開始せず、無音経路の開始には別の明示操作が必要です。

## 必要環境

- 初期デプロイ対象としてmacOS 14.2以降
- 初期実機検証対象としてApple Silicon
- macOSアプリホストにはSwift 6ツールチェーンとXcode

最新の自動検証記録はmacOS 26.6.2、Xcode 26.6、Swift 6.3.3で実行されています。この結果は、対応対象のすべてのOS・機器構成で動作する証拠ではありません。

## ビルドとテスト

パッケージテストを実行します。

```sh
swift test
```

共有Xcode schemeをビルドしてテストします。

```sh
xcodebuild \
  -project MonoOto.xcodeproj \
  -scheme MonoOto \
  -destination 'platform=macOS,arch=arm64' \
  test
```

Xcodeで`MonoOto.xcodeproj`を開くと、無音の出力機器テスト用ホストを使用できます。ビルド成功やモックテストを、物理機器の固定・切断停止が成立した証拠として扱わないでください。

出力の所有者は利用終了時に`stop()`または`dispose()`を明示的に呼びます。メインスレッド上で最後の所有者を解放した場合も、その場でバックエンドを破棄します。別スレッドでの最後の解放はMainActorへ破棄を送り、その間に配送された障害通知でも停止しますが、MainActorが実行不能な間の即時停止は保証しません。

## リポジトリ構成

- `App/` — 出力機器を選択し、無音で経路を試す最小SwiftUIホスト
- `Sources/MonoOtoCore/` — 決定的DSP、出力制限、ファイル処理
- `Sources/MonoOtoAudio/` — Core Audioの出力機器・ライフサイクル境界
- `Tests/` — DSP、ファイル経路、再生状態、出力境界のテスト
- `SPEC.md` — 現在の日本語のプロダクト・評価仕様
- `docs/superpowers/plans/` — 実装計画とタスクの判定条件
- `docs/verification/` — 実行済み確認と、明示した未検証条件

## 安全性と対象範囲

- 実機試験を始めるときは、アプリとOSの音量を低く保ってください。
- デジタル値のdBFS上限は、耳元の音圧dB SPLを制限しません。
- 違和感、痛み、耳鳴り、疲労が生じた場合は直ちに中止してください。
- 診断、聴力測定、補聴器・人工内耳の調整、緊急音の検出には使用しないでください。
- 音色手がかりの弁別を、ステレオ定位の証明として説明しないでください。

MonoOtoは音声をローカルで処理します。現在の実装は音声を送信せず、通常再生音声を保存しません。アカウントやクラウドサービスも必要ありません。
