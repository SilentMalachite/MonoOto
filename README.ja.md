# MonoOto

[English](README.md)

MonoOtoは、片耳でステレオ音楽を聴く人が、左右チャンネル由来の情報を音色の手がかりによって区別できるかを調べる、実験段階のmacOS音声プロジェクトです。

両耳聴の回復、自然なステレオ定位の再現、聴力の改善、安全な音圧を保証するものではありません。左右チャンネルの識別実験に成功しても、それは人工的な手がかりを利用できたことを示すものであり、自然な空間聴覚の実証ではありません。

## プロジェクトの状態

MonoOtoは段階Aの初期工学試作です。完成した音楽プレーヤーではなく、公開済みリリースもありません。

現在の実装範囲:

- 決定的なステレオからモノラルへの符号化、共通ゲイン、SRC、最終先読みリミッター
- WAV／AIFFの検証とworker側の有界処理
- C11フレームキューとAudioBufferListのrender境界
- 明示的な機器・耳選択、ファイル再生、処理状態を保持する一時停止、停止、シーク
- 同じ処理経路を通るメモリ上の短い確認音
- 最小SwiftUIホストと寿命・PCMの自動テスト

2026-09-11時点で、タスク6の再生統合とレビュー指摘3件の修正をコミット`88b6ddd`としてmainへマージ・push済みです。アプリは停止状態で起動し、ファイルを開く操作や出力変更では再生しません。再生と確認音には明示操作と機器・耳の選択が必要です。一時停止はpipelineと待ちPCMを保持し、停止とシークは旧セッションを破棄します。

マージ後の最新SwiftPM実行は157テスト成功、Releaseパッケージビルドも成功しました。レビュー修正後にはworker／ControllerのTSan 47テストとXcode Releaseアプリビルドも成功しています。以前のXcodeテストとASanは対象範囲・リビジョンが異なるため、最終版の検証と混同せず検証記録を参照してください。

タスク6全体の受け入れは**未完了**です。物理的な停止・pause／EOF末尾の連続性、統合音声経路の切断・スリープ、機器を使う60分再生、callback全経路の確保・寿命プロファイルは未検証です。macOS 14.2実機と知覚評価も残っています。以前のタスク5のCキュー負荷試験では代用しません。今回のコマンド・結果・証拠の限界は[検証記録](docs/verification/stage-a.md)を参照してください。完成版の設定UIと評価機能は後続タスクです。

## 必要環境

- 初期デプロイ対象としてmacOS 14.2以降
- 初期実機検証対象としてApple Silicon
- macOSアプリホストにはSwift 6ツールチェーンとXcode

最新の自動検証記録はmacOS 26.6.2、Xcode 26.6、Swift 6.3.3で実行されています。この結果は、対応対象のすべてのOS・機器構成で動作する証拠ではありません。

## ビルドとテスト

パッケージテストを実行します。

```sh
swift test
```

共有Xcode schemeをビルドしてテストします。

```sh
xcodebuild \
  -project MonoOto.xcodeproj \
  -scheme MonoOto \
  -destination 'platform=macOS,arch=arm64' \
  test
```

Xcodeで`MonoOto.xcodeproj`を開くと、最小再生ホストを使用できます。ビルド成功やモックテストを、物理機器の固定・切断停止が成立した証拠として扱わないでください。

再生の所有者は利用終了時に`stop()`を呼び、`waitUntilSettled()`で完了を待ちます。停止入口で音声ゲートを閉じ、producerとrenderの所有権が終了するまで処理資源を保持します。別スレッドでの最後の解放はMainActorへ出力の終了処理を送ります。MainActorや機器の停止が滞った場合も、物理的な即時無音を保証するものではありません。

## 試作版の使い方

1. 出力機器と聞こえる耳を選びます。起動時はどちらも未選択です。
2. 対応するWAV／AIFFを開きます。開くだけでは再生しません。
3. 明示的に再生します。一時停止は処理状態を保持し、停止は先頭に戻ります。
4. 比較モード、手がかりの設定、音量、ミュートを調整します。モノラル音源を開く際は、非対応のL/R単独モードだけ通常モノラルへ戻し、他の設定は保持します。
5. ファイルはスライダーでシークできます。確認音は同じ処理経路を通り、シークはできません。確認音の途中でファイルを開くとファイルのシークへ戻ります。

現在は最小UIです。設定の永続化、比較・評価画面の仕上げ、VoiceOverの全操作確認は後続作業です。最新のUI自動操作ではファイル選択パネルを取得できず、修正後の画面操作の通し確認は未完了です。Controllerの振る舞いは回帰テストで確認しています。

## 安全性と対象範囲

- 実機試験を始めるときは、アプリとOSの音量を低く保ってください。
- デジタル値のdBFS上限は、耳元の音圧dB SPLを制限しません。
- 違和感、痛み、耳鳴り、疲労が生じた場合は直ちに中止してください。
- 診断、聴力測定、補聴器・人工内耳の調整、緊急音の検出には使用しないでください。
- 音色手がかりの弁別を、ステレオ定位の証明として説明しないでください。

MonoOtoは音声をローカルで処理します。現在の実装は音声を送信せず、通常再生音声を保存しません。アカウントやクラウドサービスも必要ありません。
